# NeoVitaDB submission files

Ready-to-submit entry for [NeoVitaDB](https://github.com/robin994/NeoVitaDB-Catalog)
(the successor of VitaDB). New entries go to the test catalog first:
https://github.com/robin994/NeoVitaDB-Catalog-Test

- `apps/vita/2385-vibe.json` → copy to `apps/vita/` in the test catalog
- `icons_vita/2385-vibe.png` → copy to `icons_vita/`

The catalog downloads the VPK from this repo's latest GitHub release (`*.vpk`),
so a release with `vibe.vpk` attached must exist first.
